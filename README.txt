MY PERSONAL LIBRARY - JSON VERSION

1. Copy the folder to E:\xampp\htdocs\personal_library_json
2. Open http://localhost/personal_library_json/
3. No MySQL and no phpMyAdmin are required.
4. All data is stored in data/library.json.
5. Backup the whole folder or simply copy data/library.json.

Features: Dashboard, Books CRUD, multiple tags, tag search/edit/delete, shelves CRUD,
lending/return, search/filter, cover URL, responsive Bootstrap UI and scrollable book modal.
